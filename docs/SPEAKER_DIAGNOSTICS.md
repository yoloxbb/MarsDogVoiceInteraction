# 声纹低分排查

## 先固定比较对象

声纹注册页的原始浏览器 WAV 可以是 44.1/48 kHz。保存样本时，服务端先运行上传 VAD，
再转为 16 kHz 单声道 PCM16，并用这段 16 kHz 音频提取 embedding。浏览器录音格式
和服务端保存格式是两个不同阶段；`source_sample_rate=44100` 本身不代表采样率错配。

测试时先确认 `config/voice.yaml` 所指的模型和阈值、当前服务进程的启动时间、
以及样本编号。样本更新后要确认运行中的声纹索引已经同步。对历史录音，使用
`--sample-ids` 固定**录音发生时**已存在的样本编号，避免用后来新增的样本解释旧日志。

## 用已有录音定位故障层

开启 `audio_debug.enabled`，按 `utterance_id` 找到同一句的
`01_raw_capture.wav`、`02_vad_segment.wav`、`03_asr_input.wav` 和日志。
分别试听并检查有没有断字、重叠人声、机械噪声、回声或长时间静音。
`03_asr_input.wav` 是会话内声纹识别实际使用的音频；唤醒声纹需单独定位唤醒
缓存及其日志，不可混为一条样本。正式 Sherpa Provider 返回的
`speaker_confidence` 是最大模板余弦分数，即使结果是 `unknown` 也保留该分数；
它不是校准后的“是主人”概率。mock 模式的值没有声纹统计意义。

在仓库根目录执行，例如：

```bash
.venv/bin/python scripts/diagnose_speaker.py --speaker owner \
  --sample-ids 1,2,3 \
  --probe-owner /tmp/voice_debug/已确认主人句子的utterance_id/03_asr_input.wav \
  --probe-other /tmp/voice_debug/已确认其他人句子的utterance_id/03_asr_input.wav \
  > /tmp/speaker-diagnostic.json
```

`--probe-owner` 和 `--probe-other` 的身份必须由现场人员确认；未确认的音频用
`--probe-unknown`。脚本只读样本和探针文件，不注册、删除或改写任何声纹。它报告
采样率、声道、时长、RMS、峰值、削波比例、每条模板的余弦分数及保存向量与 WAV
重提取的一致度。非 16 kHz 探针使用与上传归一化相同的 polyphase 重采样，然后
以 16 kHz 提取 embedding；网页下载的探针**不再额外运行服务端上传 VAD**，所以
应在页面上采用 VAD 建议范围并试听。若要复现一次真实注册结果，应查实际保存的 WAV。

## 对比网页与节点录音

在声纹注册页 `/speaker-enrollment` 用**同一个人、同一麦克风、同一位置、同一句
连续 3–5 秒的话**录制两次：一次保持浏览器默认处理，一次勾选“诊断模式”。
页面显示浏览器报告的设备、采样率、回声消除、降噪、自动增益和编码格式。两次都
采用 VAD 建议范围，试听后点击“下载所选 WAV”；本步骤不要点击“保存为声纹样本”。
诊断模式仅向浏览器请求关闭处理，实际效果以页面报告的设置和试听结果为准；
MediaRecorder 仍由浏览器编码，下载的 PCM WAV 是解码后的结果。

随后用节点直采说相同的话，按该句的 `utterance_id` 保存
`03_asr_input.wav`。给三个文件都标为 `--probe-owner`，在同一套模板上比对
`best_score`、时长和音质。再收集已确认的其他人音频作为 `--probe-other`。
每条探针都应只有一位说话人；不要把多人语音或未确认身份的历史句子当反例。

| 观察结果 | 优先排查 |
|---|---|
| 保存向量与保存 WAV 重提取不一致 | 注册时写盘、模型版本或重新加载索引 |
| 网页高分，节点直采低分 | 采集设备设置、增益、VAD 边界、回声与节点音频缓冲 |
| 浏览器默认与关闭处理请求的分数差异明显 | 浏览器音频处理；核对页面实际报告的开关与编码格式 |
| 三条链路都低分且试听完整 | 样本代表性、模型域适配、语音时长和注册/测试语句差异 |
| 主人与其他人的分数分开，但主人落在配置阈值下 | 再收集足量标注样本后校准阈值 |
| 主人与其他人的分数重叠 | 单纯降低阈值会增加误认，优先改善采集与样本/模型 |

单次命中或一次主人/他人分数间隔不能用于调阈值。建议在同一设备上收集至少
10–20 条主人及其他人的独立句子，覆盖短句和较长句，再分别统计拒识和误识。
